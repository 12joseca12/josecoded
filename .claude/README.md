# .claude del repo

Copia de los agentes y skills de `claude-config` que usa josecoded, para que las sesiones en la nube (sin `~/.claude`) trabajen igual que en local. La fuente de verdad sigue siendo `~/Documents/GitHub/claude-config`: si se cambia allí, se vuelve a copiar aquí (no editar estas copias a mano).

- Agentes: arquitecto, implementador-web, revisor, revisor-seguridad, revisor-accesibilidad, qa, usuario-ejemplo, ui, ux.
- Skills: puerta-calidad, vercel-react-best-practices, web-design-guidelines y las de movimiento de Emil (animate, emil-design-eng, review-animations, improve-animations, find-animation-opportunities).
- Plugins (`settings.json`): superpowers, cloudflare, impeccable, taste-skill.

En la nube no hay: vault de Obsidian, codebase-memory, `/cierre`, `/cerebro`, CLI de Supabase con sesión ni Docker.
