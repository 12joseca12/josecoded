# E2E (Playwright)

`pnpm e2e` runs the URL matrix, headers and the `/dev/ui` primitives against the local OpenNext preview.

## Screenshot baselines

`dev-ui.spec.ts` and `shell.spec.ts` (header, footer and open menu, task 2.3) compare screenshots (`toHaveScreenshot`, tolerance `maxDiffPixelRatio: 0.02` in `playwright.config.ts`).
Baselines in `*-snapshots/` must be generated by the **same browser CI uses** (`playwright install chromium`). Never
generate them locally or in the cloud container: its preinstalled Chromium renders differently and CI goes red.
`updateSnapshots: 'missing'` is not used on purpose: a missing baseline must fail, not pass silently.

To create or refresh them:

1. GitHub, Actions, **Update e2e snapshots**, Run workflow on the branch (input `spec`, default `dev-ui.spec.ts`; run it again with `shell.spec.ts` for the shell baselines).
2. The workflow builds like the CI `e2e` job, runs Playwright with `--update-snapshots`, and commits changed
   `*-snapshots/` PNGs to that branch as `test(web): update e2e snapshots from CI browser`.
3. That commit is made with `GITHUB_TOKEN`, so it does not trigger CI: re-run CI (or push an empty commit) afterwards.
4. Review the PNGs in the commit before merging.
